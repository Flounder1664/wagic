#turnlimited is per-ABILITY - so two speed cards on the battlefield each fired once and
#a single life loss raised speed TWICE. The rule now lives on the tracker token, of which
#there is only ever one, so two speed cards must still give exactly one increment.
#Walking Sarcophagus and Nesting Bot are both out; the Goblin connects once; speed = 2.
#Asserted by id, not by name: "Start Your Engines" is ALSO a Kaladesh sorcery (KLD 417708).
#Rules::getMTGId resolves an unqualified name through getCardByName's cache, so which card it
#returns depends on what earlier tests looked up - this passed alone and failed after
#speed_tracker_token once _STARTENGINES_ stopped creating the tracker by name. The tracker is
#created by id (-692082), so the assertion pins that id.
#The tracker has since been renamed "Start Your Engines!" - its printed name - which ends
#the clash; the id stays the unambiguous key.
